# Reclama — presentación V4 para revisión del equipo

- [PowerPoint editable de seis diapositivas](Reclama_Hackathon_6_slides_v4.pptx). La tabla de métricas y el diagrama son elementos nativos; se comprobó la estructura y el renderizado de las seis diapositivas, pero no la edición dentro de Microsoft PowerPoint.
- [PDF de seis páginas](Reclama_Hackathon_6_slides_v4.pdf). Las páginas 1–4 conservan el PDF vectorial anterior; las páginas 5–6 son imágenes rasterizadas del PPTX V4 para reflejar las cifras y el acceso correctos. Para editar, usar el PPTX.
- [Contenido y notas](../SLIDES_6_CONTENT.md) y [valores visibles](metrics-v4.json).

La V4 separa tres pruebas locales: 28/28 casos HTTP, 160/160 aserciones repetidas y 2/2 handoffs preparados ES/PT. El modelo congelado obtuvo 218/256 aciertos frente a 168/256 de reglas en textos sintéticos reservados. Estas cifras miden objetos distintos y no representan resoluciones financieras.

La demo y el repositorio siguen privados por decisión del propietario. La diapositiva final indica que faltan la aceptación del login alojado con dos cuentas reales y la decisión sobre acceso de jueces. Ni este PPTX ni el PDF se enviaron a los organizadores. La versión V3 queda como antecedente y contiene afirmaciones de acceso público que ya no deben usarse para la entrega.

El material usa datos de demostración inventados y agregados; no incluye registros originales, credenciales ni archivos que otorguen acceso al dataset. Un expediente recibido requiere revisión humana: Reclama no decide fraude ni emite reembolsos.
