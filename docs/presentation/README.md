La revisión 3 incorpora el modelo v2 evaluado sobre 256 textos y 128 familias. Muestra 218/256 aciertos frente a 168/256 de reglas, con limitaciones explícitas. El uso es como sugerencia con confirmación. Las pruebas HTTP y aserciones de contratos se presentan por separado.

El prototipo recibe solicitudes para revisión humana en un sandbox. No adjudica fraude, no autoriza reembolsos ni mueve dinero. La política pública y el frontend están verificados; el login real de plataforma sigue pendiente de validación. No se afirma autenticación productiva completa ni envío al hackathon.

La copia pública del PPTX retira de sus notas la referencia al archivo privado de acceso al dataset y cita el reporte agregado del repositorio. No cambia ninguna diapositiva visible. No incluye registros originales, credenciales, URLs firmadas ni rutas personales. El PDF conserva solo enlaces al prototipo y al repositorio.
