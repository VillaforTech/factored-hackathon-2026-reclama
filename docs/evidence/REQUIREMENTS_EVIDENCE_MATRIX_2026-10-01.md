## Denominadores y latencia local

Cada escenario tuvo **cinco intentos independientes dentro de un servidor local tibio**, todos aprobados: 15/15 recorridos de software. p95 usa máximo por rango más cercano con n=5. El reloj va del primer `/api/message` a la relectura/auditoría y comprobación final; excluye login, creación de run, navegador, tiempo del usuario y revisión humana. No extrapolar a producción ni sumar con las 160 aserciones repetidas.

| Escenario | Resultado seguro observado | p50 / p95 de secuencia local | Solicitudes |
| --- | --- | --- | --- |
| Normal ES | 5/5 expedientes de intake persistidos y releídos | 88,33 / 204,16 ms | 30 |
| Ambiguo PT | 5/5 aclaraciones, cero casos escritos | 20,49 / 31,35 ms | 10 |
| Handoff PT | 5/5 expedientes de soporte persistidos y releídos | 69,92 / 80,14 ms | 30 |

El costo medido se limita a 70 solicitudes y tiempo local; el [modelo condicional](CASE_COST_MODEL_2026-09-30.md) usa tarifas publicadas de Workers/D1, sin confirmar que sean el plan o la factura del sitio actual. No hubo llamada externa de API de modelo registrada en este recorrido; el costo total sigue desconocido.

**Verificación local de este paquete V5:** `npm run check` (TypeScript y lint de aplicación), `npm run build` (Worker bundle), `npm run test:provenance` (6/6), `git diff --check`, hashes de nueve fuentes y del MP4, y decodificación completa del MP4 pasaron. El nuevo video y la documentación no cambian el modelo congelado. No hay CI remoto para estos archivos hasta una integración autorizada.
